## Active memory

Owner decisions (James, 2026-11-02):

- Claude app Projects come into the workspace by **sorted import** (instructions, memory and files reviewed and approved), not a raw copy.
- Import is **offered as the last step** of setup and migration, after the workspace is adapted, and is available any time later. Owners may import many projects.
- Imported work is filed wherever this workspace's setup keeps work (projects, clients or the owner's own word); never assume client or project.
- **Both shapes are supported**: every project gets a folder opened by one shared `project` skill; a project with its own repeatable steps may also get its own skill.
- **Exception to "never build skills for end users"**: project skills made by the import, each approved by the owner and installed with **Save skill**.
- Setup and migration include instructions for creating skills inside Cowork.
