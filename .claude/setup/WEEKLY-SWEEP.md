# Weekly memory sweep in Claude Cowork

Memory maintenance is optional. For an on-demand run, ask: “Run the personal-memory skill, section Weekly Sweep.” Use the installed personal-memory package and the attached workspace; do not copy maintainer sources into it.

Before any cleanup, follow installed personal-memory’s recovery and authority rules. Its `sweep.py` preview deletes nothing. Deletion requires the documented Git safety checks, current permission, and recoverable content; no Git or unverifiable bytes means no deletion. Changing standing preferences or procedures still requires explicit approval. Do not use a sweep to delete legacy skill sources or clear audit failures.

The owner may choose to run this weekly themselves. If they ask for scheduling, first verify whether their Cowork installation provides a local scheduled-task feature that can access this workspace and installed helpers. Do not invent a headless Cowork command or substitute another agent app. A cloud runner that cannot see the workspace is not suitable. If local access cannot be verified, keep maintenance on demand and explain why.

Agree the schedule, retention scope and approval requirements before enabling anything. Test one real run, inspect its changes and checks, and record how the owner pauses it. Do not claim a schedule is working until that run succeeds in the owner’s app. Preserve backups and disclose any unavailable automated checks.
