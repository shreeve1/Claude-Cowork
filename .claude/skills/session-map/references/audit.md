# Audit a map

The checker runs at the start and end of every map session. Do a full audit when it reports drift, after several days, before route review, or when the owner asks.

The checker validates fields, stages, dependencies, briefs, evidence paths, placeholders, size and Git drift. Fix every error; fix each warning or record in the Log why it stands.

Then answer only the judgment checks the checker cannot settle, with evidence:

- Does Done evidence prove its done-when?
- Is each Active stage really in progress, and is **Where it stopped** accurate?
- Is each drift commit assigned to a stage or noted as unrelated?
- Are Decisions, Constraints and Found along the way still true?
- Does the remaining route reach the Destination?
- Do Open questions still block?

Fix how-level problems directly. Gather what-questions for the owner into one message. Log the audit and commit.

Done when the checker reports zero errors, each judgment check has an evidence-based answer, and fixes are committed.
